# KonthoDub — AI ডাব, ভিডিও থেকে অডিও ও অডিও রিপ্লেস

একটা Android অ্যাপ (Flutter), যা দিয়ে তিনটা কাজ করা যায়:

1. **এক্সট্রাক্ট:** ভিডিও থেকে MP3 অডিও বের করা।
2. **AI ডাব:** যেকোনো ভাষার ভিডিও/অডিও বাংলা বা হিন্দিতে ডাব করা, ছেলে-মেয়ে আলাদা ভয়েসসহ।
3. **রিপ্লেস:** ভিডিওর পুরনো অডিও সরিয়ে নতুন অডিও বসানো।

## ফিচার

### ১. এক্সট্রাক্ট
- ভিডিও বাছুন, MP3 (192 kbps) পাবেন।
- সেভ হয়: `Internal storage/AudioTool/Extracted_Audio`

### ২. AI অটো ডাব
ভিডিও বা শুধু অডিও দিলে অ্যাপ নিজে থেকে নিচের ধাপগুলো চালায়:

1. অডিও বের করে (mono, 16 kHz)।
2. **Groq Whisper** দিয়ে কথা টেক্সট ও টাইমিংসহ বের করে।
3. **Gemini** দিয়ে প্রতিটা অংশে বক্তা ছেলে না মেয়ে তা চেনে (ঐচ্ছিক)।
4. Google Translate দিয়ে বাংলা/হিন্দিতে অনুবাদ করে, তারপর Google TTS দিয়ে ভয়েস বানায়।
5. টাইমিং অনুযায়ী ভয়েসগুলো বসিয়ে ফাইনাল ফাইল তৈরি করে (ffmpeg)।

**ভয়েস**
- মেয়ে: Google TTS-এর স্বাভাবিক ভয়েস।
- ছেলে: একই ভয়েসের পিচ কমানো সংস্করণ (গতি একই থাকে)।
- ছেলে-মেয়ে সনাক্ত বন্ধ থাকলে বা Gemini ব্যর্থ হলে সবাই একই ভয়েসে ডাব হয়।

**মিউজিক ও সাউন্ড ইফেক্ট**
- "আসল মিউজিক ও সাউন্ড ইফেক্ট রাখুন" সুইচ চালু (ডিফল্ট) থাকলে কথার ফাঁকে আসল অডিও জোরে শোনা যায়, কথা চলার সময় নিচে নামে (স্লাইডারে ০–৪০%, ডিফল্ট ১২%)।
- মিউজিক আলাদা করা যায় না, তাই কথার ওপর মিউজিক থাকলে সেই অংশে মিউজিকও কমে যায়, আর আসল কথাও আবছা শোনা যেতে পারে। সুইচ বন্ধ করলে শুধু ডাবের ভয়েস থাকে।

**সেভ হয়**
- ভিডিও: `AudioTool/AI_Dubbed_Video`
- অডিও: `AudioTool/AI_Dubbed_Audio`

### ৩. অডিও রিপ্লেস
- ভিডিও ও নতুন অডিও বাছুন। ভিডিও স্ট্রিম কপি হয়, শুধু অডিও বদলায়।
- সেভ হয়: `AudioTool/Replaced_Video`

### ব্যাকগ্রাউন্ডে চলা
- কাজ শুরু হলে একটা নোটিফিকেশন আসে (ফোরগ্রাউন্ড সার্ভিস)। স্ক্রিন অফ করলে বা অন্য অ্যাপে গেলেও কাজ চলতে থাকে।
- প্রথমবার নোটিফিকেশন ও ব্যাটারি অপটিমাইজেশন পারমিশন চাইবে, দুটোই দিন।
- অ্যাপ জোর করে বন্ধ করলে (recent থেকে সরালে) কাজ থেমে যায়।

### থিম
- ফোনের সিস্টেম সেটিং অনুযায়ী লাইট বা ডার্ক মোড নিজে থেকে বদলায়।

### লগ
- উপরের 🐞 আইকনে সব ধাপের লগ দেখা যায়। কপি বা শেয়ার করা যায়।
- অ্যাপ ক্র্যাশ করলেও লগ ফাইলে সেভ থাকে।

## API Key (দুটোই ফ্রি)

| Key | কী কাজে | কোথায় পাবেন |
|---|---|---|
| Groq | কথা থেকে টেক্সট (Whisper) | console.groq.com/keys |
| Gemini | ছেলে-মেয়ে সনাক্ত (ঐচ্ছিক) | aistudio.google.com/apikey |

key অ্যাপে বসিয়ে **সেভ** চাপুন। সেভ করার সময় অ্যাপ key যাচাই করে। key ফোনের অ্যাপ-ফোল্ডারে ফাইলে থাকে, কোথাও আপলোড হয় না (শুধু ওই সার্ভিসের API-তে যায়)।

## সীমাবদ্ধতা

- **একসাথে অনেকজন কথা বললে** ডাব ঠিকমতো আলাদা হয় না। Whisper কথাগুলো মিশিয়ে ফেলতে পারে, আর Gemini পুরো অংশে একটাই লেবেল দেয়।
- **একাধিক ছেলে বা মেয়ে** থাকলে প্রত্যেকে একই ছেলে/মেয়ের ভয়েস পায়।
- ওভারল্যাপ, খারাপ অডিও, বাচ্চার গলা বা খুব ভারী গলার মেয়ে/চিকন গলার ছেলের ক্ষেত্রে Gemini ভুল করতে পারে।
- Gemini ধাপে অডিও প্রায় ৭০ মিনিটের বেশি লম্বা হলে ওই ধাপ বাদ যায়, তখন সবাই একই ভয়েসে ডাব হয়।
- Google Translate ও Google TTS অনানুষ্ঠানিক এন্ডপয়েন্ট, ভবিষ্যতে বদলে বা বন্ধ হয়ে যেতে পারে।
- পুরো কাজ চলার সময় স্থির ইন্টারনেট দরকার। নেটওয়ার্ক সমস্যায় প্রতিটা ধাপ কয়েকবার আবার চেষ্টা করে।
- ফ্রি লিমিট: অনেক সেগমেন্টের অডিও বারবার চালালে Gemini/Groq 429 দিতে পারে। কিছুক্ষণ পরে আবার চেষ্টা করুন।

## বিল্ড (GitHub Actions)

1. এই ফোল্ডার GitHub রিপোতে পুশ করুন।
2. `.github/workflows/build.yml` নিজে থেকে চলে: Android প্রজেক্ট তৈরি করে, minSdk ও পারমিশন ঠিক করে, তারপর release APK বানায়।
3. Actions-এর শেষে **`audio-tool-apk`** আর্টিফ্যাক্ট থেকে `app-arm64-v8a-release.apk` নামান।
4. ফোনে ইনস্টল করে প্রথমবার স্টোরেজ পারমিশন দিন। না দিলে ফাইল অ্যাপের নিজস্ব ফোল্ডারে সেভ হবে।

হাতে বিল্ড করতে চাইলে Flutter stable (SDK ≥ 3.3) লাগবে:

```bash
flutter create --platforms=android --project-name audio_tool --org com.audiotool .
flutter pub get
flutter build apk --release --split-per-abi
```

## আপডেট (পুরনো অ্যাপ মুছে না ফেলে)

- Android শুধু একই সাইনিং key-র APK দিয়ে আপডেট করতে দেয়। এই প্রজেক্টে `ci/debug.keystore` ফাইলটা সবসময় একই key দিয়ে সাইন করে, তাই এরপর থেকে নতুন APK সরাসরি পুরনোটার ওপর ইনস্টল হবে।
- **`ci/debug.keystore` কখনো মুছবেন না বা বদলাবেন না।** বদলালে আবার পুরনো অ্যাপ মুছে নতুন করে ইনস্টল করতে হবে।
- প্রতিটা বিল্ডে ভার্সন নম্বর (`--build-number`) নিজে থেকে বাড়ে।
- যে ফোনে আগের (অন্য key-র) APK আছে, সেখানে প্রথমবার একবার পুরনোটা মুছতে হবে।

## প্রজেক্টের গঠন

```
assets/icon.png               অ্যাপের লোগো
android_res/                  লোগোর Android আইকন (বিল্ডের সময় বসে)
ci/debug.keystore             সাইনিং key (মুছবেন না)
lib/main.dart                 পুরো অ্যাপ (UI, লগ, ffmpeg, Groq, Gemini, TTS)
pubspec.yaml                  ডিপেন্ডেন্সি
.github/workflows/build.yml   APK বিল্ড
```

**মূল প্যাকেজ:** `ffmpeg_kit_flutter_new_audio`, `file_picker`, `path_provider`, `share_plus`, `http`, `permission_handler`, `flutter_foreground_task`

## সমস্যা হলে

1. অ্যাপের লগ খুলে কপি করুন।
2. লগে `❌` বা `⚠️` চিহ্নিত লাইন খুঁজুন।
3. সাধারণ কারণ:
   - `Groq error 401`: Groq key ভুল।
   - `Gemini 404`: মডেলের নাম বন্ধ হয়েছে। `_identify` ফাংশনের `models` তালিকা বদলান।
   - `Failed host lookup`: ইন্টারনেট কেটে গেছে।
   - `TTS error 429`: Google TTS সাময়িকভাবে সীমা দিয়েছে, কিছুক্ষণ পরে চেষ্টা করুন।
